01问题引入：Agent 工具循环的三大保命问题

当大模型开始调用外部工具时，在真实世界里几乎每分钟都会遇到三种意外：① 模型犯傻陷入死循环，没完没了地调同一个工具；② 模型传了一个越界参数（比如把音量设成 150 或运动时长设成 99999 毫秒）；③ 设备 Wi-Fi 刚好卡了一下超时了。

配电箱空气开关直觉

有界 for 循环（range(max_rounds)）是定时断电器——最多允许转 3 圈，到点必须停；函数（def）是标准插座契约——规定好插什么参数、返什么结果；异常捕获（try/except）则是支路保险丝——就算烤面包机短路了，只跳那一路闸并回报“操作失败”，绝不能让整栋大楼（整个语音服务器）停电闪退！

02零基础拆桥：循环、推导式、函数契约与 try/except

拆桥 1：有界 for 循环与“一行流”列表推导式还原

1 · 普通 for 循环（一步步看懂） 
# range(3) 依次产出 0, 1, 2（共 3 次，天然防死循环！）
for round_index in range(3):
    if round_index == 2:
        break  # break 意思是“立刻跳出整个循环，不再往下转”
    print(f"第 {round_index + 1} 轮")

# 下面两段代码 100% 等价（右边浓缩版叫“列表推导式”）：
texts = []
for item in content_list:
    if item.get("type") == "text":
        texts.append(item["text"])

以后在 AI 生成的源码里看到 [表达式 for 变量 in 列表 if 条件] 不用慌——它只是把左边的 4 行新建空列表 + 循环 + 判断 + append 浓缩成了一行！

2 · Deskbot 源码里的列表推导式真身 
    text_parts = [item["text"] for item in result.get("content", []) if item.get("type") == "text"]

逐词翻译：遍历工具返回的 content 列表里的每一项 item，如果它的 "type" 是 "text"，就把它的 "text" 字段取出来装进新列表 text_parts。

拆桥 2：函数 def（return vs print）与 try / except 保险丝

**args 字典解包魔法：如果 args = {"level": 80}，那么写 set_volume(**args) 就等价于写 set_volume(level=80)！这正是工具调度器把 JSON 字典喂给 Python 函数的核心桥梁。
1 · 函数契约与异常拦截 
# 星号 * 后面的参数必须写名字调用，如 set_volume(level=80)
def set_volume(*, level: int) -> dict:
    if not 0 <= level <= 100:
        raise ValueError("音量必须在 0..100 之间")
    return {"success": True, "volume": level}

try:
    out = set_volume(level=150)  # 触发 ValueError，立刻跳去 except
except ValueError as err:
    out = {"success": False, "error": str(err)}
print("程序没崩，安全拿到：", out)

死磕区分 print 和 return：print(...) 只是往人类屏幕上印一行字，函数本身交回的是空值 None；只有写 return 结果，调用它的上层程序才能真正拿到数据继续往下传！

2 · Deskbot 工具名映射小函数 
def _model_tool_name(name: str) -> str:
    # Function calling endpoints may only accept letters, digits, '_' and '-'.
    # Keep firmware names intact on the wire and separate browser/device tools.
    return "device_" + name.replace(".", "_")

很多大模型 API 不允许函数名里带点号 .（如固件上报的 self.motion.stop），这个 2 行小函数把点号替换成下划线并加上前缀，返回 "device_self_motion_stop"。

来看 Deskbot 真正执行工具的核心函数 _execute_impl。你会惊喜地发现：虽然它有 28 行，但用到的全是我们刚学过的 not in、isinstance、and/or 和 try/except！点击右侧卡片逐段点亮：

        original_name = next((name for name in device_tool_names if _model_tool_name(name) == call.name), call.name)
        call = ToolCall(call.id, original_name, call.arguments)
        try:
            if call.name not in available_names:
                if call.name == "self.camera.take_photo":
                    return self._text({"success": False, "error": "设备没有上报拍照工具，请检查固件中的相机初始化和工具注册"})

                return self._text({"success": False, "error": error})
            arguments = json.loads(call.arguments or "{}")
            if not isinstance(arguments, dict):
                return self._text({"success": False, "error": "工具参数必须是对象"})
            if call.name in device_tool_names:
                if call.name.startswith("self.motion.") and call.name not in {"self.motion.stop", "self.motion.get_status"}:

                        return self._text({"success": False, "error": "运动工具必须使用 1 到 5000 毫秒的 duration_ms"})

                    return self._text({"success": False, "error": "实机 MCP 未连接"})

            else:

                    "name": call.name, "arguments": arguments,
                })
        except (aiohttp.ClientError, asyncio.TimeoutError, ConnectionError):

  1. 还原真实工具名：把模型叫的 device_self_motion_stop 还原回设备认识的 self.motion.stop。
  2. 第一道岗哨（已知工具检查）：如果模型瞎编了一个不在 available_names 集合里的工具名，立刻 return 错误 JSON，绝不往下发请求。
  3. 第二道岗哨（参数类型与运动安全限幅）：检查参数是不是字典；如果是运动指令，强制要求 duration_ms 是 1..5000 之间的整数（注意 isinstance(True, int) 在 Python 里居然是 True，所以代码特地先排除了 isinstance(duration, bool)！）。
  4. 保命保险丝（except 兜底）：不管是网络断连超时，还是 json.loads 解析坏字符串抛出 ValueError，统统抓起来转成干净的 {"success": False, "error": ...} 返回，语音服务稳如泰山！

06本课浓缩与面试表达

三句话记住本课精髓
  • 循环必设上限：凡是让大模型驱动的工具循环，外层必须套上 max_rounds 硬上限，绝不写无保底的 while True。
  • 函数分清存与调：TOOLS = {"name": func} 存的是函数对象（不加括号），取出后 func(**args) 才是真正调用。
  • 工具层不抛裸异常：工具边界要把超时、断连、坏参数统一捕获并翻译成结构化 {"success": False, "error": "..."}，交给上层循环决策（对应本仓课程 Ch.02 Errors are also turns）。
Python 细节彩蛋 · 面试官超爱问的小坑

「在写工具参数校验时有个经典的 Python 陷阱：bool 其实继承自 int，所以 isinstance(True, int) 的结果是 True（且 True == 1）！如果只写 isinstance(duration, int) and 1 <= duration <= 5000，模型误传 duration_ms=true 就会混过校验变成运动 1 毫秒。因此在 Deskbot 里我们专门写了 if isinstance(duration, bool) or not isinstance(duration, int) 先把布尔值挡在门外。」
